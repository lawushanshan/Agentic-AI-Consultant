# 员工请假制度

## 1. 适用范围

本制度适用于公司全体正式员工（含试用期）。实习生、兼职人员参照执行，具体由人力资源部解释。

## 2. 请假类型与天数

| 请假类型 | 年度天数上限              | 说明                                     |
| -------- | ------------------------- | ---------------------------------------- |
| 年假     | 5~15天（按司龄）          | 入职满1年享5天，每增加1年多1天，15天封顶 |
| 病假     | 12天（带薪）              | 需提供二级以上医院证明                   |
| 事假     | 10天（无薪）              | 须提前申请，紧急情况除外                 |
| 婚假     | 13天（自然日）            | 含法定节假日，凭结婚证申请               |
| 产假     | 98天（女）/15天（男陪产） | 按国家规定执行，需提前1个月报备          |
| 丧假     | 1~3天                     | 直系亲属3天，旁系1天                     |

## 3. 审批流程

- **1天以内（含）**：直属上级审批 → 系统自动备案
- **1~3天**：直属上级 → 部门负责人 → HR备案
- **3天以上**：直属上级 → 部门负责人 → HR总监 → 总经理（7天以上需总经理审批）

## 4. 请假操作步骤

1. 登录OA系统 → 进入“考勤中心” → 选择“请假申请”；
2. 填写请假类型、起止时间、事由；
3. 上传附件（如需证明）；
4. 提交审批，系统自动推送至对应审批人；
5. 审批通过后，考勤记录自动更新。

## 5. 违规处理

- 未办理请假手续擅自离岗，按旷工处理；
- 旷工累计超过3天，视为严重违纪，公司有权解除劳动合同。

## 6. 补充说明

- 年假可拆分半天使用，需提前2个工作日申请；
- 病假超过3天需提交诊断证明原件；
- 所有请假以系统审批通过时间为准，口头/微信请假不作为正式依据。

**生效日期**：2025年1月1日
**修订单位**：人力资源部
