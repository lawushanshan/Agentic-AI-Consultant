# 报销流程说明

## 1. 报销范围

- 差旅费（交通、住宿、餐饮补贴）
- 业务招待费（客户餐叙、礼品，需提前报备）
- 办公用品采购费（单笔≥100元）
- 通讯费（每月固定额度内）
- 培训费、会议费（凭会议通知）

## 2. 报销标准速查表

| 费用类型             | 标准上限    | 备注                   |
| -------------------- | ----------- | ---------------------- |
| 住宿费（一线城市）   | 500元/晚    | 含早餐                 |
| 住宿费（二线及以下） | 350元/晚    | 含早餐                 |
| 交通费（市内）       | 实报实销    | 需提供打车发票或地铁票 |
| 餐饮补贴             | 80元/天     | 按出差自然日计算       |
| 业务招待             | 人均≤200元 | 需附客人名单及事由     |

## 3. 报销流程（共5步）

1. **填写报销单**：登录财务系统 → “费用报销” → 新建报销单，选择费用类型；
2. **上传票据**：拍照或扫描发票、行程单、支付截图（必须清晰可辨）；
3. **部门审批**：直属上级审核费用的真实性与合理性（24小时内）；
4. **财务审核**：财务核对票据合规性、预算占用情况（48小时内）；
5. **出纳支付**：审核通过后，次周周五统一打款至工资卡。

## 4. 重要时间节点

- 费用发生日后 **15个自然日内** 必须提交报销申请，逾期不予处理；
- 每月25日为当月报销截止日，25日之后提交的顺延至下月。

## 5. 常见退单原因

- 发票抬头错误（须为“杭州XX科技有限公司”）
- 缺少消费明细（如住宿水单、菜单）
- 超标部分未单独说明
- 电子发票未上传验真截图

## 6. 紧急报销通道

若因供应商预付款等紧急情况，可邮件申请“绿色通道”，由财务总监特批，3个工作日内处理。
