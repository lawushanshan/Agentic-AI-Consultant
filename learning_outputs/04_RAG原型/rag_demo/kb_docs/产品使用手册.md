# 产品使用手册 — 智能办公助手 V3.2

## 1. 产品简介

智能办公助手是一款集日程管理、会议纪要、任务跟踪于一体的AI工具，支持Web端、iOS/Android App及微信小程序。

## 2. 快速入门（5分钟上手）

### 2.1 注册与登录

- 使用公司企业邮箱注册，接收验证码激活；
- 支持SSO单点登录（对接钉钉/飞书）；
- 首次登录后，建议完成“新手引导”获取基础积分。

### 2.2 主界面布局

- **左侧导航栏**：首页、日程、任务、文档、设置；
- **顶部操作栏**：搜索框、通知铃铛、个人头像；
- **右侧工作区**：显示当前模块内容。

## 3. 核心功能详解

### 3.1 智能日程

- 点击“+”新建日程，支持自然语言输入，例如“下周二下午3点与市场部开会”；
- 系统自动识别时间、参与人，并发送会议邀请；
- 支持日历视图（日/周/月），可拖拽调整时间。

### 3.2 会议纪要

- 在日程中开启“AI记录”功能，会议中自动录音并转文字；
- 会后自动生成纪要草稿，包括决议事项、待办负责人；
- 支持一键分享给与会人员。

### 3.3 任务看板

- 采用Kanban模式：待处理 → 进行中 → 审核 → 已完成；
- 可为任务设置优先级（P0~P3）、截止日期、子任务；
- 任务评论支持@提及同事。

## 4. 常用快捷键（Web端）

- `Ctrl + K`：全局搜索
- `Ctrl + N`：快速新建任务
- `Ctrl + Shift + M`：打开会议记录
- `Esc`：关闭弹窗

## 5. 移动端使用技巧

- 左滑任务可快速更改状态；
- 长按日程可复制或删除；
- 支持语音输入创建日程（仅App）。

## 6. 数据安全与备份

- 所有数据加密存储，每日自动备份；
- 离职员工账号自动冻结，数据移交至直属上级。

## 7. 常见操作报错及解决

| 报错提示     | 原因             | 解决办法           |
| ------------ | ---------------- | ------------------ |
| “网络异常” | 服务端超时       | 检查网络，刷新重试 |
| “权限不足” | 未分配该模块权限 | 联系管理员开通     |
| “同步失败” | 日历冲突         | 手动选择空闲时段   |
