# 售后服务规则

## 1. 总则

为保障消费者合法权益，明确我司售后责任，依据《中华人民共和国消费者权益保护法》及相关法规，制定本规则。所有通过我司官方渠道购买的产品，均适用本规则。

## 2. 保修政策

| 产品类别     | 整机保修 | 主要部件保修      | 备注               |
| ------------ | -------- | ----------------- | ------------------ |
| 智能办公设备 | 1年      | 2年（主板、屏幕） | 人为损坏不保       |
| 家居生活类   | 2年      | 3年（电机）       | 耗材（滤网等）不保 |
| 软件订阅服务 | 按订阅期 | 不适用            | 赠送免费技术支持   |

**保修起始日**：以发票开具日期或电子订单完成日期为准。

## 3. 非保修范围

- 因使用不当、进水、摔落等人为因素导致的损坏；
- 未经授权私自拆机或维修；
- 超过保修有效期；
- 无法提供有效购买凭证；
- 自然磨损、外观刮擦不影响使用功能。

## 4. 售后响应时效

| 服务类型         | 响应时间           | 解决时间              |
| ---------------- | ------------------ | --------------------- |
| 在线咨询（文字） | 5分钟内            | 即时                  |
| 电话热线         | 30秒内接通         | 按问题复杂度          |
| 上门维修（城市） | 预约后48小时内     | 上门后2小时内         |
| 寄修服务         | 签收后48小时内检测 | 检测后3个工作日内修复 |
| 退换货审核       | 收到申请后24小时内 | 审核后3个工作日内处理 |

## 5. 退换货细则

- **7天无理由退货**：需保持商品全新、附件齐全，运费由买家承担（赠品需一并退回）；
- **15天质量问题换货**：经检测确属质量问题，免费换新，运费由我司承担；
- **30天性能故障退货**：经维修两次仍无法正常使用，可要求退货退款。

## 6. 维修费用说明

- 保修期内：免费维修（非人为），更换部件免费；
- 保修期外：收取配件费+人工费（人工费标准：80元/台）；
- 检测后用户放弃维修，需支付30元检测费。

## 7. 用户义务

- 在申请售后时，如实描述故障现象，提供清晰照片或视频；
- 寄回维修时妥善包装，避免运输二次损坏；
- 配合售后工程师远程诊断。

## 8. 争议处理

如对售后服务有异议，可向平台投诉或向当地消费者协会申请调解。协商不成的，可向公司所在地人民法院提起诉讼。
